# Portafolio de Proyectos | Ciencia de Datos, Machine Learning, Deep Learning y Computación Cuántica

Bienvenido a mi repositorio de proyectos. Aquí encontrarás implementaciones reproducibles y rigurosas enfocadas en **Analítica de Datos, Aprendizaje Automático (ML/DL) y Computación Cuántica**, aplicadas a datos de diversas naturalezas.


## Tecnologías y Herramientas

* **Lenguajes:** Python, LaTeX.
* **Machine Learning & Deep Learning:** PyTorch, TensorFlow, Scikit-learn.
* **Computación Cuántica:** Qiskit, PennyLane.
* **Análisis de Datos & Estadística:** NumPy, Pandas, SciPy, Statsmodels, Matplotlib, Seaborn.

## Estructura del Portafolio

Todos los proyectos dentro de este repositorio están diseñados bajo los siguientes principios:
1. **Reproducibilidad:** Código estructurado, entornos documentados y datos accesibles.
2. **Documentación Clara:** Explicación teórica del problema, decisiones metodológicas y análisis de resultados.
3. **Comparación Rigurosa:** Evaluación de modelos utilizando métricas estadísticas estándar y estrategias de validación cruzada.

*Puedes explorar las carpetas individuales para ver la documentación, los problemas abordados y el código fuente.*
